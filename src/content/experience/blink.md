## Overview

As co-founder and lead engineer, I built Blink's web application and financial analysis backend. The [live application](https://blinkos.app) brings financial statements and transactions into dashboards and AI-assisted reports for small businesses.

- Built the React client for onboarding, dashboards, and report review.
- Developed the FastAPI and LangGraph workflow that analyzes financial data and gathers additional business context through a chat interview.
- Integrated Xero data syncing with OAuth, encrypted refresh tokens, and shared rate limiting.
- Used DuckDB for financial analysis, PostgreSQL for application data, and Redis for caching and coordination.
